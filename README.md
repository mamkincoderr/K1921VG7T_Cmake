# К1921ВГ7Т. Учебный проект

Прошивка для отладочной платы **NIIET-MINI-K1921VG7T**, обозначение КФДЛ.441461.043, ревизия 2.0.
На плате стоит микроконтроллер **К1921ВГ7Т**, ядро RISC-V.

После прошивки программа печатает в последовательный порт короткий отчёт и мигает светодиодом
раз в секунду. Нажатие пользовательской кнопки печатает дату и время.

## Что подготовить

* Компьютер с Windows.
* Кабель USB-C. Им плата и питается, и говорит с компьютером.
* Программатор **WCH-LinkE** и шлейф к разъёму XP7.
* [MounRiver Studio](http://www.mounriver.com/download). В ней открывают проект, собирают и смотрят отладчик.
* CMake 3.20 или новее и Ninja. В PowerShell:

```powershell
winget install --id Kitware.CMake --exact
winget install --id Ninja-build.Ninja --exact
```

* Python с пакетом pyserial. Он нужен для прошивки через USB-UART:

```powershell
pip install pyserial
```

Компилятор GCC НИИЭТ и OpenOCD в репозиторий не входят. Их скачивает скрипт из открытых
репозиториев НИИЭТ на GitFlic. Команда ниже, из корня этого проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\fetch.ps1
```

## Перемычки

![Три перемычки](docs/img/jumpers.svg)

Для работы примера:

1. Поставить перемычку **XP3** (BT.EN).
2. Поставить перемычку **XP4** (BT.RST).
3. Снять перемычку **XP8** (SERVEN).

XP4 пропускает сигнал DTR от микросхемы CH340 на сброс микроконтроллера.
Если терминал при открытии порта поднимает DTR, плата сидит в сбросе и молчит.
В настройках терминала **DTR и RTS выключены**.

## Программатор

WCH-LinkE один раз переводится в режим CMSIS-DAP: зажать кнопку ModeS и вставить адаптер в USB.
Синий светодиод адаптера остаётся включённым. В диспетчере устройств Windows идентификатор
`VID_1A86&PID_8012`.

Шлейф идёт на **XP7**. Земля обязательна. Питание 3,3 В с программатора на плату не подавать:
плата питается от своего USB-C. Контакта nRESET на XP7 нет.

![Провода JTAG](docs/img/jtag.svg)

| Сигнал на WCH-LinkE | Контакт XP7 | Вывод микроконтроллера |
|---|---|---|
| SWDIO / TMS | 2 | A12 |
| SWCLK / TCK | 4 | A13 |
| TDO | 6 | A15 |
| TDI | 8 | A14 |
| GND | 3, 5 или 9 | земля |
| RST | 10 | A10, можно не подключать |

Выводы A12 и A13 заняты JTAG. Светодиод и кнопка к ним не подключены.

| Функция | Вывод | Как ведёт себя |
|---|---|---|
| Светодиод B0 LED | B0 | горит, когда на выводе единица |
| Кнопка USER BTN | B1 | при нажатии ноль. Рядом загорается BTN LED |

## Собрать

Все команды ниже выполняются в каталоге проекта, там, где лежит `CMakeLists.txt`.

Открыть в MounRiver Studio: File → Import → General → Existing Projects into Workspace
и указать этот каталог. Сборка: Ctrl+B.

Из PowerShell то же самое:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run.ps1 build
```

Появляются два файла:

| Файл | Куда ляжет в Flash |
|---|---|
| `obj\bootloader\bootloader.elf` | `0x0000`…`0x1FFF`, 8 КБ, UART-загрузчик |
| `obj\K1921VG7T_Cmake.elf` | с адреса `0x2000`, само приложение |

В конце сборки печатается карта обеих областей.

## Прошить

Загрузчик записывается один раз. Повторно он нужен после полного стирания Flash.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run.ps1 boot-flash
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run.ps1 flash
```

`flash` записывает приложение по JTAG, сверяет запись и пускает кристалл.
Полное стирание Flash само по себе не запускать.

В MounRiver Studio те же действия лежат в Build Targets: `boot-flash` и `flash`.
Прошивка приложения через USB без программатора: цель `uart`. Порт при этом должен быть свободен.

Отладка: Debug → `K1921VG7T_Cmake`. Окно периферии читает `svd\K1921VG7T.svd`.

## Что должно получиться

Подключить USB-C. В диспетчере устройств появится порт CH340. Открыть его на скорости
**115200**, формат **8N1**, без DTR и RTS.

Сначала приходит отчёт. Числа АЦП на другой плате будут другими. Слова `ok` должны быть на месте.
Строка `osc 0` означает, что флаг RC-генератора часов не взведён. Следующая строка при этом
уже показывает идущие секунды.

```text
K1921VG7T, SYSCLK = 100 MHz
ADC 22 4095 1275 386 1159 ok
CRC a6d17ede ok
RTC osc 0 gpr ok
time 2026-10-04 00:00:09
DAC 2048
WDT load ok lock ok
SIU id 04e4c402 rev 2 serv 0
TMR32 0 -> 4900 runs
B1 prints time. LED B0 blinks 1 Hz
```

Дальше светодиод **B0 LED** мигает: полсекунды горит, полсекунды нет.
Нажатие **USER BTN** печатает строку `time ГГГГ-ММ-ДД чч:мм:сс`.

Коды АЦП сняты с открытых входов. Это не измеренное напряжение.
Канал 1 на проверенной плате был в упоре шкалы, код 4095.

## Если плата молчит

1. Горит ли **PWR**. Нет света: нет питания по USB-C.
2. Стоит ли **SERVEN**. Если стоит, снять.
3. Выключены ли DTR и RTS в терминале. При включённом DTR и надетой XP4 микроконтроллер в сбросе.
4. Тот ли COM-порт. Это порт CH340, не порт программатора.
5. Скорость 115200, не другая.
6. Нажата левая кнопка USER BTN, а не правая RESET.
7. Для JTAG шлейф сидит в XP7, у адаптера режим CMSIS-DAP, земля соединена.

Повторный запуск уже прошитой программы: кнопка RESET или

```powershell
python .\tools\uart_flash.py --reset
```

## Где что лежит

| Папка | Содержимое |
|---|---|
| `user\` | пример: мигание, консоль, проверки периферии |
| `sdk\include\` | карта регистров и заголовки ядра |
| `sdk\ll\` | короткие функции работы с блоками, один каталог заголовков |
| `sdk\source\` | старт, такт, прерывания |
| `bootloader\` | UART-загрузчик, отдельная программа |
| `ld\` | раскладка приложения во Flash и RAM |
| `openocd\` | настройки программатора |
| `docs\` | рисунки платы и схемы подключения |
| `tools\` | сборка, прошивка, скачивание компилятора |

Новый файл `.c` в `user\` подхватывается сборкой сам.

Комментарии в исходниках на русском. Строки, которые уходят в UART, на латинице:
так их одинаково видно в любом терминале.

## Память

| Область | Адрес | Размер |
|---|---|---|
| Загрузчик | `0x0000` | 8 КБ |
| Приложение | `0x2000` | остальной Flash, всего Flash 512 КБ |
| ОЗУ | `0x20000000` | 32 КБ |

Кварц на плате 16 МГц. Ядро в этом примере работает около 100 МГц.
Системный таймер, от которого идёт миллисекундная задержка, находится по адресу `0xE0000000`.

На кристалле нет отдельных блоков CRC, HASH и CRYPTO. Контрольная сумма в примере считается программой.
Часы хранят число секунд. Календарь программа вычисляет из этого числа.

## Чего не делать

* Не ставить перемычку SERVEN.
* Не вызывать программный сброс `RCU->RSTSYS` и не запускать в OpenOCD процедуру `k1921vg7t_sw_reset`.
  После серии таких сбросов контроллер Flash зависал. После прошивки кристалл пускает команда `k1921_run`.
* Не поднимать частоту JTAG. В настройке проекта она 100 кГц.
* Не стирать всю Flash, пока отдельно не решено поставить загрузчик заново.
* Не включать сторожевому таймеру бит сброса в учебном примере.

Короткий журнал проверки на плате: [docs/СОСТОЯНИЕ.md](docs/СОСТОЯНИЕ.md).
