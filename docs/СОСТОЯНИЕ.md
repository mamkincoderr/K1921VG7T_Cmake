# Что уже проверено на плате

Плата NIIET-MINI-K1921VG7T, КФДЛ.441461.043 rev 2.0. Кристалл К1921ВГ7Т.
Инструкция, рисунки и схемы подключения: [README](../README.md).

4 октября 2026 пример из `user\main.c` был прошит по JTAG и прочитан через OpenOCD и UART.

| Что смотрели | Результат |
|---|---|
| Связь с кристаллом | IDCODE `0xDEB14001`, идентификатор SIU `0x04E4C402`, ревизия 2 |
| Частота | UART печатает `SYSCLK = 100 MHz` |
| UART0 | отчёт целиком принят на 115200, выводы A8 и A9 |
| АЦП | пять кодов с каналов 0…4, блок ответил готовностью |
| CRC | программная проверка сошлась. Отдельного блока CRC на кристалле нет |
| RTC | секунды идут от даты старта. Бит готовности RC-генератора остаётся сброшенным |
| ЦАП | в регистре данных код 2048, выходной буфер включён |
| Сторожевой таймер | значение записано, замок закрыт, сброс от таймера выключен |
| Таймер TMR32_0 | счётчик изменился с 0 на 4900 и затем остановлен |
| Светодиод B0 | вывод настроен на выход, программа доходит до мигания |
| Кнопка USER BTN | в той сессии её не нажимали. Вывод B1 сидит в единице за счёт подтяжки |

Сервисный режим был выключен: перемычка SERVEN снята, бит в SIU равен нулю.
