## JTAG: WCH-LinkE R0-1v3 в режиме CMSIS-DAP -> XP7

Отладчик один раз переключается в режим CMSIS-DAP: зажать ModeS и вставить его в USB. Синий
светодиод остаётся включённым, Windows показывает VID_1A86&PID_8012.

| Сигнал | Вывод WCH-LinkE | Вывод XP7 | Вывод МК |
|---|---|---|---|
| TCK | SWCLK/TCK | 4 | A13 |
| TMS | SWDIO/TMS | 2 | A12 |
| TDI | TDI | 8 | A14 |
| TDO | TDO | 6 | A15 |
| GND | GND | 3, 5 или 9 | - |
| TRST | RST | 10 | A10 (необязателен, работает и без него) |

Не соединять 3V3 отладчика с VREF (XP7-1): плата питается от своего USB-C.
В XP7 нет nRESET. Аппаратный сброс потребовал бы провода к EXT.RST# (XP5-25), проект его не
использует.

## UART-загрузчик: USB-C -> CH340B

| Функция | Вывод | Примечание |
|---|---|---|
| UART0 RX | A8 | альтернативная функция 1 |
| UART0 TX | A9 | альтернативная функция 1 |
| BOOT.EN# | A6 | RTS# через перемычку **XP3**; низкий уровень = остаться в загрузчике |
| BOOT.RST# | сброс МК | DTR# через перемычку **XP4** |

Для прошивки по UART установить XP3 и XP4. Перед записью по JTAG скрипт тоже дёргает XP4,
чтобы оживить флеш-контроллер. Пуск после записи идёт через JTAG (`k1921_run`), не через DTR.
При установленной XP4 терминал, поднявший DTR,
удерживает МК в сбросе, пока порт открыт. Перемычку SERVEN (XP8) в обычной работе снять: она
включает сервисный режим кристалла (аварийное стирание защищённой Flash командой `srv_erase`
в OpenOCD). Для прошивки и отладки она не нужна, при установленной SERVEN прошивка не
запускается как обычно.

## Ввод-вывод платы, который использует пример

| Элемент | Вывод | Уровень |
|---|---|---|
| светодиод B0 LED (VD5) | B0 | горит при 1 |
| кнопка USER BTN (SB2, левая) | B1 | 0 при нажатии, одновременно загорается BTN LED |
| кнопка RESET (SB1, правая) | сброс микроконтроллера | к выводу B1 не подключена |

BSP из SDK НИИЭТ использует для них A12/A13, а на этой плате это TMS/TCK.
